# ระบบนัดหมายผู้ป่วย รพ.สต. (งานกายภาพบำบัด)

เว็บแอประบบนัดหมายผู้ป่วย ใช้ **Google Sheet เป็นฐานข้อมูล** ผ่าน **Google Apps Script**
เป็น backend และโฮสต์หน้าเว็บด้วย **GitHub Pages** — ไม่มีค่าใช้จ่าย

## สิทธิ์การใช้งาน

| ทำได้ | นักกายภาพ | เจ้าหน้าที่นัดหมาย |
|---|:---:|:---:|
| ทำนัด / ดูนัด / แก้ไขเลขบัตรประชาชน | ✅ | ✅ |
| บันทึก "มาทำกายภาพแล้ว" | ✅ | ❌ |
| แก้ไขรหัส ICD ของนัดที่จองไปแล้ว | ✅ | ❌ |
| ตั้งช่วงเวลานัดรายวัน / วันปิด / เปิดรับพิเศษ / เวลาพิเศษเสริม | ✅ | ❌ |
| ตั้งประเภทคลินิก / กฎคลินิกอัตโนมัติ / กฎปิดอัตโนมัติ | ✅ | ❌ |
| ตั้งช่วงไม่ว่าง (ประชุม/ทำเอกสาร/อบรม/ลา) | ✅ | ❌ |
| จัดการรายการรหัส ICD-10 / ICD-9 | ✅ | ❌ |
| ดูหน้า "สถิติ" | ✅ | ❌ |

รองรับเจ้าหน้าที่นัดหมายหลายคน — เพิ่มได้ง่ายๆ โดยเพิ่มแถวในชีต `Users` (ดูหัวข้อ "เพิ่มผู้ใช้งาน" ด้านล่าง)

## ฟีเจอร์หลัก

### ปฏิทินและการนัดหมาย
- **ช่วงเวลานัดกำหนดเองได้อิสระ** ต่อวันในสัปดาห์ ไม่ใช่การหารเวลาเท่าๆ กัน (เช่น 09:00-10:00, 10:01-11:00, พักเที่ยง, 13:30-14:30 ก็ได้)
- นัดหมายแบ่งเป็น **OPD** และ **ลงชุมชน**
- ข้อมูลที่บันทึกต่อ 1 นัด: **ชื่อ, นามสกุล, หมู่** (บังคับ), **เบอร์โทร, เลขบัตรประชาชน** (ไม่บังคับ, แก้ไขภายหลังได้ในหน้ารายละเอียดนัด), หมายเหตุ, รหัส **ICD-10/ICD-9**
- คลิกรายการนัดเพื่อเปิดดูรายละเอียดเต็ม และแก้ไขเลขบัตรประชาชน/รหัส ICD ได้แม้นัดนั้นจองไปแล้ว
- **บันทึกว่าคนไข้มาทำกายภาพแล้ว** — กดปุ่ม "มาแล้ว ✓" เก็บวันเวลา+ผู้บันทึกไว้ในชีต (คอลัมน์ `attendedAt`, `attendedBy`) ใช้ทำสถิติภายหลัง นัดที่บันทึกว่ามาแล้วจะยกเลิกนัดไม่ได้ (ต้องยกเลิกการบันทึกก่อน)
- วันนี้ถูกไฮไลต์พื้นหลังสีเขียวเด่นในปฏิทิน ส่วนวันที่จองเต็มทุกช่วงเวลาจะเป็นพื้นแดงพร้อมป้าย "เต็ม"
- แต่ละวันโชว์ป้าย "ว่างอีก N" บอกจำนวนช่องที่ยังจองได้ โดยไม่ต้องกดเข้าไปดู

### รหัส ICD ต่อนัด
- **ICD-10** 2 ช่อง: ช่องแรกล็อกเป็น `Z501` อัตโนมัติทุกนัด (ลบไม่ได้), ช่อง 2 เลือกจากรายการที่ตั้งไว้
- **ICD-9** 6 ช่อง: ช่องแรกล็อกเป็น `9339` (ประเมินทางกายภาพบำบัด) อัตโนมัติ, ช่อง 2-6 เลือกเองได้ทีละช่อง
- จัดการรายการรหัสที่เลือกได้ในหน้า "ตั้งค่า" หัวข้อ "รายการรหัส ICD-10 / ICD-9"

### การกำหนดเวลาเปิด-ปิด (ทั้งหมดแก้ไขได้ในหน้า "ตั้งค่า" ของนักกายภาพ)
- **ช่วงเวลานัดรายวัน** — ตารางเวลาปกติประจำสัปดาห์ (จันทร์-ศุกร์ เปิดได้; เสาร์-อาทิตย์ปิดตายตัว) กำหนดช่วงเวลาเองได้อิสระต่อวัน
- **วันปิดเฉพาะกิจ** — ปิดทั้งวันเป็นรายวันที่ เช่น วันหยุดนักขัตฤกษ์ (เพิ่มเองทีละวัน หรือกด "ดึงวันหยุดราชการ" เพื่อดึงวันหยุดนักขัตฤกษ์ทั้งปีจากปฏิทินของ Google มาเพิ่มให้อัตโนมัติในครั้งเดียว — เลือกปี พ.ศ. ที่ต้องการแล้วกดได้ทุกเมื่อ ระบบจะเพิ่มเฉพาะวันที่ยังไม่มีอยู่แล้วเท่านั้น ไม่ซ้ำ)
- **เปิดรับพิเศษ** — ในแผงรายละเอียดวัน คลิกวันที่ปกติปิดแล้วกด "เปิดรับพิเศษวันนี้" เพื่อเปิดนัดเฉพาะวันนั้น กำหนดช่วงเวลาเองได้ (ระบบดึงช่วงเวลาปกติของวันในสัปดาห์นั้นมาเป็นค่าตั้งต้นให้)
- **เพิ่มเวลาพิเศษเฉพาะวันเดียว** — ปุ่ม "+ เพิ่มเวลาพิเศษวันนี้" ในแผงรายละเอียดวัน เพิ่มช่วงเวลาเสริมเข้าไปจากตารางปกติ เฉพาะวันนั้นวันเดียว ไม่กระทบวันอื่นหรือตารางประจำสัปดาห์ ใช้ได้ทั้งวันที่เปิดอยู่แล้ว (เพิ่มช่วงเสริม) และวันที่ปกติปิด (เปิดเฉพาะช่วงที่เพิ่ม) ลบทีละรายการได้
- **ตั้งช่วงไม่ว่าง** — บล็อกเวลาเฉพาะวันที่ระบุ (ประชุม/ทำเอกสาร/อบรม/ลา)
- **ปิด/ไม่ว่างอัตโนมัติ (ตามวัน)** — กฎที่เกิดซ้ำทุกเดือนโดยไม่ต้องตั้งทีละวัน เลือกได้ 2 แบบ:
  1. **ตามวันในสัปดาห์+ความถี่** เช่น "ทำเอกสาร ทุกวันศุกร์สัปดาห์สุดท้ายของเดือน" หรือ "ประชุม ทุกวันจันทร์"
  2. **ตามวันที่ในเดือน** เช่น "ปิดทั้งวัน ทุกวันที่ 1" หรือ "ปิดทั้งวัน ทุกวันสุดท้ายของเดือน"

  ถ้าไม่ระบุช่วงเวลาจะปิดทั้งวัน ถ้าระบุจะบล็อกเฉพาะช่วงนั้น — "เปิดรับพิเศษ" ยังชนะกฎนี้ได้เสมอถ้าต้องการเปิดวันนั้นจริงๆ

ลำดับความสำคัญเวลาระบบตัดสินว่าวันไหนเปิด/ปิด: **เปิดรับพิเศษ** > **วันปิดเฉพาะกิจ / กฎปิดอัตโนมัติ** > **ตารางเวลาประจำสัปดาห์** จากนั้น **เวลาพิเศษเสริม** และ **ช่วงไม่ว่าง (รวมที่มาจากกฎอัตโนมัติ)** จะถูกรวม/หักออกเป็นลำดับสุดท้ายเสมอ

### คลินิกประจำวัน
- ตั้งชื่อ+สีคลินิกเอง (เช่น คลินิกข้อเข่า, คลินิกป้องกันล้ม, คลินิกลดปวด) ไม่จำกัดจำนวน
- กำหนดคลินิกให้วันใดวันหนึ่งแบบเจาะจงได้ในแผงรายละเอียดวัน พร้อม note สั้นๆ (เช่น "pain-knee")
- **กฎคลินิกอัตโนมัติ** — ตั้งเงื่อนไขครั้งเดียว เช่น "คลินิกป้องกันล้ม ทุกวันอังคารที่ 4 ของเดือน" ระบบขึ้นป้ายให้เองทุกเดือน (การกำหนดแบบเจาะจงวันสำคัญกว่ากฎเสมอถ้าตั้งไว้ทับกัน)
- เลือก "ไม่มีคลินิก (เฉพาะวันนี้)" ได้ถ้าต้องการปิดป้ายคลินิกของวันนั้นวันเดียวแม้มีกฎตรงกัน
- ชื่อคลินิกจะแสดงเป็นบรรทัดแรกเด่นชัดบนสุดของแต่ละวันในปฏิทิน

### หน้า "สถิติ" (เฉพาะนักกายภาพ)
สรุปจำนวนนัด/มารับบริการ/ไม่มาตามนัด/คนไข้ไม่นับซ้ำ แยกตามประเภทนัด คลินิก หมู่ และวันในสัปดาห์ พร้อมกราฟแนวโน้ม เลือกช่วงเวลาเองได้หรือกดปุ่มลัด (เดือนนี้ / เดือนที่แล้ว / ปีงบประมาณนี้ / ปีนี้) **ไม่แสดงชื่อหรือข้อมูลส่วนตัวของคนไข้** มีแต่ตัวเลขสรุป — "อัตรามาตามนัด" คำนวณเฉพาะนัดที่ผ่านไปแล้วนับจากวันแรกที่เริ่มมีการกดบันทึก "มาแล้ว" เท่านั้น

### รองรับมือถือ/แท็บเล็ต
ปฏิทิน แผงรายละเอียดวัน และโมดัลต่างๆ ปรับขนาดให้ใช้งานสะดวกบนจอแคบ

### หน้า "ตั้งค่า"
แต่ละหัวข้อพับ/ขยายได้ (เริ่มต้นพับเก็บไว้ทั้งหมด กดที่ชื่อหัวข้อเพื่อดู)

## ขั้นตอนติดตั้ง

### 1. สร้างฐานข้อมูล (Google Sheet + Apps Script)

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น `ฐานข้อมูลนัดหมาย รพสต`
2. เมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในโปรเจกต์นี้
4. กด **Save** จากนั้นเลือกฟังก์ชัน `setupSheets` ที่แถบด้านบน แล้วกด **Run**
   - ครั้งแรกจะมีหน้าต่างขอสิทธิ์ (authorize) ให้กด "อนุญาต" (โปรเจกต์นี้เป็นของคุณเอง ปลอดภัย)
   - จะได้ชีตย่อยทั้งหมด: `Users`, `Schedule`, `ScheduleSlots`, `ClosedDates`, `Busy`, `BusyRules`, `Appointments`, `ClinicTypes`, `ClinicDays`, `ClinicRules`, `SpecialOpen`, `SpecialOpenSlots`, `ExtraSlots`, `Icd10Codes`, `Icd9Codes`
   - มีผู้ใช้เริ่มต้นสร้างให้ 2 คน: `physio` / `staff` รหัสผ่าน `changeme123`
     **ให้เข้าไปแก้รหัสผ่านในชีต `Users` ทันทีก่อนใช้งานจริง** (ห้ามตั้งรหัสเป็นตัวเลขล้วน เพราะ Google Sheets จะเก็บเป็นตัวเลขและเทียบรหัสไม่ตรง — ใส่ตัวอักษรปนด้วย)
   - **ถ้าเคยติดตั้งไว้แล้วก่อนหน้านี้:** รัน `setupSheets` ซ้ำได้อย่างปลอดภัย ข้อมูลเดิมจะไม่ถูกลบหรือรีเซ็ต แค่จะสร้างชีต/คอลัมน์ที่ยังไม่มีเพิ่มให้เท่านั้น
5. เมนู **Deploy > New deployment**
   - เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** ที่ได้ (ลงท้ายด้วย `/exec`)
6. **(แนะนำ) ตั้งตัวปลุกระบบกัน cold start** — ไอคอนนาฬิกา (Triggers) ด้านซ้าย > Add Trigger > เลือกฟังก์ชัน `keepWarm` > Time-driven > Minutes timer > Every 10 minutes > Save ช่วยให้เว็บตอบสนองเร็วขึ้นตอนไม่มีคนใช้งานมาสักพัก

**เมื่อแก้ `Code.gs` ในรอบต่อๆ ไป** ต้องทำ 2 ขั้นเสมอ: (1) Save แล้ว (2) **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** — แค่ Save อย่างเดียวจะยังไม่มีผลกับเว็บจริง

### 2. ตั้งค่าหน้าเว็บ

1. เปิดไฟล์ `docs/app.js`
2. แก้บรรทัด
   ```js
   const API_URL = 'https://script.google.com/macros/s/PASTE_YOUR_DEPLOYMENT_ID/exec';
   ```
   ให้เป็น URL ที่คัดลอกมาจากขั้นตอนที่ 1

### 3. อัปโหลดขึ้น GitHub + เปิด GitHub Pages

1. สร้าง repository ใหม่บน GitHub (อันที่ใช้เฉพาะงานนี้ อย่าปนกับโปรเจกต์อื่น) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
2. ไปที่ **Settings > Pages** ของ repository
3. ในหัวข้อ Build and deployment เลือก Source: **Deploy from a branch**
   - ถ้าไฟล์เว็บ (`index.html`, `style.css`, `app.js`) อยู่ในโฟลเดอร์ `docs/` ตั้ง Branch: `main` โฟลเดอร์: **/docs**
   - ถ้าไฟล์เหล่านี้ถูกอัปโหลดไปอยู่ที่ root ของ repo โดยตรง (ไม่มีโฟลเดอร์ `docs/`) ให้ตั้งโฟลเดอร์เป็น **/ (root)** แทน — เช็คได้จากหน้ารายการไฟล์ใน repo ว่า `index.html` อยู่ที่ไหน
   - กด Save
4. รอสักครู่ GitHub จะแสดงลิงก์เว็บไซต์ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
5. เปิดลิงก์นั้น เข้าสู่ระบบด้วยผู้ใช้ที่ตั้งไว้ในขั้นตอนที่ 1

**เมื่อแก้ไฟล์ `app.js` / `index.html` / `style.css` ในรอบต่อๆ ไป** เปิดไฟล์บน GitHub กดไอคอนดินสอ วางเนื้อหาใหม่ทับ แล้ว Commit — จากนั้นรีเฟรชเว็บแบบล้าง cache (Ctrl+Shift+R) เพื่อให้แน่ใจว่าเห็นเวอร์ชันล่าสุด

## เพิ่มผู้ใช้งาน

เพิ่มเจ้าหน้าที่นัดหมายหรือนักกายภาพคนอื่นได้ไม่จำกัดจำนวน โดยไม่ต้องแก้โค้ด:

1. เปิดชีต `Users` ในสเปรดชีตฐานข้อมูล
2. เพิ่มแถวใหม่ 1 แถวต่อ 1 คน กรอก `username`, `password`, `role` (`staff` หรือ `physio`), และ `displayName`
3. ผู้ใช้คนนั้นเข้าสู่ระบบได้ทันที ไม่ต้อง deploy ใหม่ (อาจมีผลช้าถึง 30 นาทีเพราะระบบแคชรายชื่อผู้ใช้ไว้)

## หมายเหตุด้านความปลอดภัยและข้อมูล

- ระบบนี้ออกแบบให้ติดตั้งและดูแลเองภายในหน่วยงาน ใช้รหัสผ่านแบบง่ายที่เก็บในชีต `Users` — **ควรตั้งรหัสผ่านที่คาดเดายากและเปลี่ยนเป็นระยะ**
- ข้อมูลที่บันทึก (ชื่อ-นามสกุล, หมู่, เบอร์โทร, และโดยเฉพาะ **เลขบัตรประชาชน**) ถือเป็นข้อมูลส่วนบุคคล/ข้อมูลอ่อนไหวตาม PDPA ควร:
  - จำกัดสิทธิ์การเข้าถึง Google Sheet เฉพาะผู้ที่เกี่ยวข้องเท่านั้น (Share แบบ "จำกัดเฉพาะบุคคลที่ระบุ" ห้ามตั้งเป็นลิงก์สาธารณะ)
  - เก็บเลขบัตรประชาชนเท่าที่จำเป็นจริงๆ เท่านั้น เว้นว่างได้หากไม่จำเป็นต้องใช้ยืนยันตัวตน
  - ไม่บันทึกรายละเอียดการวินิจฉัยหรือประวัติการรักษาลงในช่อง "หมายเหตุ"
- หน้า "สถิติ" ไม่แสดงชื่อหรือข้อมูลส่วนตัวคนไข้ เหมาะสำหรับดูภาพรวมโดยไม่ละเมิดความเป็นส่วนตัว
- Apps Script เวอร์ชันฟรีมีโควตาการเรียกใช้งานต่อวัน ซึ่งเพียงพอสำหรับการใช้งานระดับ รพ.สต. ทั่วไป และมีความหน่วงในตัวบ้าง (ปกติ 1-3 วินาทีต่อการเรียกแม้ "อุ่นเครื่อง" แล้ว) เป็นข้อจำกัดของแพลตฟอร์มฟรีที่ไม่สามารถกำจัดได้หมด
