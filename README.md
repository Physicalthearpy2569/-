# ระบบนัดหมายผู้ป่วย รพ.สต. (งานกายภาพบำบัด)

เว็บแอประบบนัดหมายผู้ป่วย ใช้ **Google Sheet เป็นฐานข้อมูล** ผ่าน **Google Apps Script**
เป็น backend และโฮสต์หน้าเว็บด้วย **GitHub Pages** — ไม่มีค่าใช้จ่าย

## สิทธิ์การใช้งาน

| ทำได้ | นักกายภาพ | เจ้าหน้าที่นัดหมาย |
|---|:---:|:---:|
| ทำนัด / ดูนัด | ✅ | ✅ |
| ตั้งเวลาเปิด–ปิดรายวัน | ✅ | ❌ |
| ตั้งวันปิดเฉพาะกิจ/วันหยุด | ✅ | ❌ |
| ตั้งช่วงไม่ว่าง (ประชุม/ทำเอกสาร/อบรม/ลา) | ✅ | ❌ |

ปฏิทินเปิดให้บริการเฉพาะ **จันทร์–ศุกร์** เสาร์-อาทิตย์และวันที่เพิ่มเป็น "วันปิดเฉพาะกิจ" (ใช้ระบุวันหยุดนักขัตฤกษ์ได้ด้วย) จะถูกล็อกอัตโนมัติ นัดหมายแบ่งเป็น **OPD** และ **ลงชุมชน**

ข้อมูลที่บันทึกต่อ 1 นัด: **ชื่อ, นามสกุล, หมู่** (บังคับกรอก) และ **เบอร์โทร, เลขบัตรประชาชน** (จะกรอกหรือไม่ก็ได้)

รองรับเจ้าหน้าที่นัดหมาย (บทบาท "staff") ได้มากกว่า 1 คน — เพิ่มได้ง่ายๆ โดยเพิ่มแถวในชีต `Users` (ดูหัวข้อ "เพิ่มผู้ใช้งาน" ด้านล่าง)

## ขั้นตอนติดตั้ง

### 1. สร้างฐานข้อมูล (Google Sheet + Apps Script)

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น `ฐานข้อมูลนัดหมาย รพสต`
2. เมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในโปรเจกต์นี้
4. กด **Save** จากนั้นเลือกฟังก์ชัน `setupSheets` ที่แถบด้านบน แล้วกด **Run**
   - ครั้งแรกจะมีหน้าต่างขอสิทธิ์ (authorize) ให้กด "อนุญาต" (โปรเจกต์นี้เป็นของคุณเอง ปลอดภัย)
   - จะได้ชีตย่อย 5 ชีต: `Users`, `Schedule`, `ClosedDates`, `Busy`, `Appointments`
   - มีผู้ใช้เริ่มต้นสร้างให้ 2 คน: `physio` / `staff` รหัสผ่าน `changeme123`
     **ให้เข้าไปแก้รหัสผ่านในชีต `Users` ทันทีก่อนใช้งานจริง**
5. เมนู **Deploy > New deployment**
   - เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วคัดลอก **Web app URL** ที่ได้ (ลงท้ายด้วย `/exec`)

### 2. ตั้งค่าหน้าเว็บ

1. เปิดไฟล์ `docs/app.js`
2. แก้บรรทัด
   ```js
   const API_URL = 'https://script.google.com/macros/s/PASTE_YOUR_DEPLOYMENT_ID/exec';
   ```
   ให้เป็น URL ที่คัดลอกมาจากขั้นตอนที่ 1

### 3. อัปโหลดขึ้น GitHub + เปิด GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (คงโครงสร้างโฟลเดอร์ `docs/` ไว้)
2. ไปที่ **Settings > Pages** ของ repository
3. ในหัวข้อ Build and deployment เลือก Source: **Deploy from a branch**
   ตั้งค่า Branch: `main` และโฟลเดอร์: **/docs** แล้วกด Save
4. รอสักครู่ GitHub จะแสดงลิงก์เว็บไซต์ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`
5. เปิดลิงก์นั้น เข้าสู่ระบบด้วยผู้ใช้ที่ตั้งไว้ในขั้นตอนที่ 1

## การใช้งานเบื้องต้น

- **นักกายภาพ** เข้าเมนู "ตั้งค่า" เพื่อกำหนดเวลาเปิด–ปิดแต่ละวัน (จ–ศ) และเพิ่ม/ลบวันปิดเฉพาะกิจ
- คลิกวันในปฏิทินเพื่อดูช่วงเวลาว่าง เพิ่มนัดหมาย หรือ (เฉพาะนักกายภาพ) ตั้งช่วงไม่ว่าง โดยเลือกประเภท ประชุม / ทำเอกสาร / อบรม / ลา — ช่วงเวลานั้นจะไม่แสดงเป็นช่องว่างให้ทำนัดอีก และจะขึ้นป้ายกำกับในปฏิทิน
- นัดหมายแต่ละช่องเลือกได้ว่าเป็น **OPD** หรือ **ลงชุมชน**

## เพิ่มผู้ใช้งาน (เจ้าหน้าที่นัดหมายคนอื่นๆ)

รองรับเจ้าหน้าที่นัดหมายเพิ่มได้ตามต้องการ (เช่น 1-4 คน) โดยไม่ต้องแก้โค้ด:

1. เปิดชีต `Users` ในสเปรดชีตฐานข้อมูล
2. เพิ่มแถวใหม่ 1 แถวต่อ 1 คน กรอก `username`, `password`, ใส่ `role` เป็น `staff`, และ `displayName` เป็นชื่อที่จะแสดงในระบบ
3. ผู้ใช้คนนั้นเข้าสู่ระบบได้ทันที ไม่ต้อง deploy ใหม่

หากต้องการเพิ่มนักกายภาพอีกคน (สิทธิ์เต็ม) ให้ตั้ง `role` เป็น `physio` แทน

## หมายเหตุด้านความปลอดภัยและข้อมูล

- ระบบนี้ออกแบบให้ติดตั้งและดูแลเองภายในหน่วยงาน ใช้รหัสผ่านแบบง่ายที่เก็บในชีต `Users` — **ควรตั้งรหัสผ่านที่คาดเดายากและเปลี่ยนเป็นระยะ**
- ข้อมูลที่บันทึก (ชื่อ-นามสกุล, หมู่, เบอร์โทร, และโดยเฉพาะ **เลขบัตรประชาชน**) ถือเป็นข้อมูลส่วนบุคคล/ข้อมูลอ่อนไหวตาม PDPA ควร:
  - จำกัดสิทธิ์การเข้าถึง Google Sheet เฉพาะผู้ที่เกี่ยวข้องเท่านั้น (Share แบบ "จำกัดเฉพาะบุคคลที่ระบุ" ห้ามตั้งเป็นลิงก์สาธารณะ)
  - เก็บเลขบัตรประชาชนเท่าที่จำเป็นจริงๆ เท่านั้น เว้นว่างได้หากไม่จำเป็นต้องใช้ยืนยันตัวตน
  - ไม่บันทึกรายละเอียดการวินิจฉัยหรือประวัติการรักษาลงในช่อง "หมายเหตุ"
- Apps Script เวอร์ชันฟรีมีโควตาการเรียกใช้งานต่อวัน ซึ่งเพียงพอสำหรับการใช้งานระดับ รพ.สต. ทั่วไป

## โครงสร้างไฟล์

```
Code.gs              ← วางในโปรเจกต์ Apps Script ของ Google Sheet
docs/
  index.html         ← หน้าเว็บหลัก
  style.css          ← สไตล์
  app.js             ← ตรรกะฝั่งหน้าเว็บ + ตัวแปร API_URL
README.md
```

## ปรับแต่งเพิ่มเติมที่ทำได้ในอนาคต

- เพิ่มการแจ้งเตือนนัดหมายผ่าน LINE Notify / SMS
- เพิ่มผู้ใช้/บทบาทเพิ่มเติมโดยเพิ่มแถวในชีต `Users`
- ปรับความถี่ของช่องเวลานัด (นาที/ช่อง) แยกตามวันได้จากเมนูตั้งค่า
